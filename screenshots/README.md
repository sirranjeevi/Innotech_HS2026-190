# 📸 Civic Complaint Portal - Application Screenshots & Demo Walkthrough

This directory contains visual captures of the key role-based workflows for hackathon evaluation and demonstration.

---

## 🖥️ Screen Previews

### 1. Public Landing Page & OpenStreetMap Geocoding
- Hero section with ambient motion video, official logo emblem, and instant Complaint ID tracker.
- OpenStreetMap interactive pin drop with live Nominatim reverse geocoding.

### 2. Citizen Workstation
- Grievance reporting form with photo upload and GPS coordinate capture.
- Scoped personal dashboard showing live 6-stage lifecycle progress.

### 3. Municipal Admin Workstation
- Real-time SLA analytics dashboard and master grievance registry.
- Department workforce assignment and duplicate complaint detection modal.
- Interactive City GIS map view with status-coded markers.

### 4. Field Worker Workstation
- Work order inbox with GPS site navigation.
- Closeout flow requiring mandatory post-resolution photo evidence upload before marking `RESOLVED`.
